# 🛒 Smart PDV & Gestão de Estoque

Sistema web de Ponto de Venda (PDV), controle de estoque e inteligência financeira desenvolvido em **Python (FastAPI)**, **SQLite** e **Tailwind CSS / Chart.js**, unindo agilidade no atendimento de balcão com indicadores claros de rentabilidade e giro de produtos.

---

### 🎯 Objetivo do Projeto
Resolver o gargalo operacional de pequenos comércios que misturam faturamento bruto com lucro líquido. O sistema automatiza a frente de caixa e transforma cada transação em dados estruturados para análise de margem, comportamento de vendas por horário e controle de estoque.

---

### ⚙️ Principais Funcionalidades
- **Frente de Caixa Ágil:** Entrada rápida via leitor de código de barras ou busca manual com visualização de imagens dos produtos.
- **Inteligência Financeira:** Calculadora integrada de troco e descontos, com separação automática entre **faturamento bruto, custo de aquisição e lucro líquido** por venda e por período.
- **Dashboard Analítico (BI):** Gráficos interativos (`Chart.js`) com volume de vendas por hora, ranking de produtos mais rentáveis, ticket médio e histórico filtrável por data.
- **Controle de Estoque & Catálogo:** Baixa automática por venda, cadastro de produtos com upload de foto, importação de catálogo e rastreabilidade das movimentações.

---

### 🛠️ Tecnologias Utilizadas
- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** HTML5, Tailwind CSS, JavaScript, Chart.js
- **Banco de Dados:** SQLite
